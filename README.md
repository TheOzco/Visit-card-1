# کارت ویزیت دیجیتال | دکتر محمد محمودیه دهکردی

کارت ویزیت تک‌صفحه‌ای موبایل‌محور با تم **لاکچری – وینتیج** (سبز زمردی و طلایی) شامل:

- عکس پروفایل با قاب طلایی
- دکمهٔ تماس مستقیم و **دکمهٔ مسیریابی به لوکیشن** (گوگل‌مپ / نشان / ویز)
- لینک به **تلگرام، اینستاگرام، ایتا، بله، روبیکا و واتساپ**
- **مراقبت‌های بعد از درمان**: ترمیم، زیبایی (ونیر کامپوزیت، لمینیت سرامیکی، بلیچینگ)، ایمپلنت، کشیدن دندان، درمان ریشه، پروتز (ثابت و متحرک)
- ذخیره در مخاطبین (فایل vCard) و اشتراک‌گذاری کارت
- جایگاه لوگو در انتهای صفحه

## ویرایش اطلاعات (حتی با گوشی)

همه‌چیز در دو فایل است:

| فایل | محتوا |
| --- | --- |
| `src/data/profile.ts` | نام، شماره‌ها، آدرس، ساعات کاری، **مختصات لوکیشن** و لینک شبکه‌های اجتماعی |
| `src/data/care.ts` | متن مراقبت‌های بعد از درمان |

عکس پروفایل: `src/assets/profile.jpg` — لوگو: `src/assets/logo.jpg` (فقط فایل را با همان نام جایگزین کنید).

برای گرفتن مختصات دقیق مطب: در گوگل‌مپ روی محل مطب نگه دارید، عدد‌های `lat, lng` را کپی و در `profile.location` بگذارید.

## انتشار روی GitHub Pages (از روی گوشی)

1. یک ریپازیتوری جدید در GitHub بسازید و این پروژه را در آن آپلود/پوش کنید.
2. از منوی ریپو وارد **Settings → Pages** شوید و در بخش *Build and deployment* گزینهٔ **GitHub Actions** را انتخاب کنید.
3. تمام! با هر تغییر در شاخهٔ `main`، ورک‌فلوی `.github/workflows/deploy.yml` پروژه را می‌سازد و منتشر می‌کند.
   آدرس نهایی: `https://<username>.github.io/<repo>/`

> خروجی بیلد یک فایل **تک‌فایلی** (`dist/index.html`) است؛ حتی می‌توانید فقط همین فایل را در شاخهٔ `gh-pages` بگذارید و مسیر Pages را روی همان برنچ تنظیم کنید.

## اجرای محلی

```bash
npm install
npm run dev     # حالت توسعه
npm run build   # خروجی در dist/index.html
```
